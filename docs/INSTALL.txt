SALMS RANDOM WINDOW — Fusion Generator v1

INSTALL
1. Double-click Salms Random Window.drfx.
2. Confirm Resolve's template installation dialog.
3. On the Edit page, open Effects Library > Generators and search for Salms Random Window (under Salms).
4. Drag it onto V2 above footage on V1, then stretch it over the section you want.
5. Select the generator and use Inspector > Generator to access its controls. Depending on Resolve's layout, expand the Image, Rectangle and Border pages/sections.
If it does not appear after installation, save your project and restart Resolve.

CONTROLS
Image: Blur Amount, Film Grain Amount (0–1 blend), Grayscale checkbox.
Rectangle: Change Every Frames (default 4), Random Seed, Minimum/Maximum Width (%), Minimum/Maximum Height (%).
Border: Border Width (normalized Fusion units), Border Color, Border Opacity.

Defaults match the working example: blur 12, grain blend 0.5, white opaque border width 0.003, width 18–58%, height 18–62%, seed 17. Grayscale defaults off and affects both sharp and blurred footage, leaving the border color independent.

Changing the seed chooses another deterministic sequence. Each rectangle stays fixed for the specified frame count. Smaller size bounds produce smaller rectangles. Reversed bounds are sorted internally. Sizes are clamped to 1–98% and the window retains a 1% image margin. Extremely thick outlines may extend beyond that margin.

TEST BEFORE REUSING
- Confirm the generator reads V1 footage, including when you move it over a different shot.
- Step through frames: at default settings, 0–3 match, 4–7 match, and frame 4 jumps.
- Set blur and grain to zero separately and confirm each response.
- Change seed, timing and each size limit; border must follow the sharp window exactly.
- Toggle grayscale; footage becomes monochrome and border keeps its selected color.
- Change border width, color and opacity.
- Stretch the clip longer and check the sequence continues.
- Test two instances with different seeds to confirm independent controls.
